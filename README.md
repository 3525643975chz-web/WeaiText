# WeaiText - 喵喵出击！ 🐾

> 一个基于 Android 无障碍服务（Accessibility Service）的**完全本地**自动文本替换与喵语化工具。

基于开源项目 `My-Word-ls-Meow` 二次魔改。在任意 App 的输入框打字时，按你预设的规则实时完成子串替换、整句替换、句尾追加（喵喵化）等操作。

全程离线运行，不申请网络权限，不上传任何数据。

---

## ✨ 核心特性与魔改记录

*   **极致视觉体验**：全新重构的 UI 界面，采用**纯白透明果冻玻璃（White Glassmorphism）**风格，完美融入二次元背景图。
*   **Q弹交互**：全局注入 `cubic-bezier(0.34, 1.56, 0.64, 1)` 动画曲线，实现按压缩放、切页回弹的果冻物理效果。
*   **无缝启动**：原生端加入了 `#06080E` 深色底色兜底，配合网页端入场动画，彻底解决 WebView 启动白屏闪烁问题。
*   **文本替换引擎**：支持多条规则组合轮询，替换结果与已有后缀自动去重。
*   **微信特供强注入**：针对微信特殊输入框，底层采用了“全选+剪贴板粘贴”的强制注入连招。
*   **输入法兼容防抖**：将延迟设置为 150ms，完美解决拼音打一半被提前替换的问题。
*   **严格白名单机制**：彻底移除原版代码里对部分 App 的“强制放行后门”，现在严格遵循用户在网页端勾选的生效领地。
*   **无痕模式**：退出即从多任务列表隐身，但无障碍服务依然在后台保活。

---

## 📱 使用说明

1. 安装后打开 App，按引导开启**无障碍服务**（本应用的服务项）。
2. 在「规则配置」页选择预设（如喵语），按需增加子串 / 整句 / 句尾附加规则。
3. 在「选择领地」页勾选你需要文本替换的应用（白名单）。
4. 打开任意聊天 App 正常打字即可看到效果。

> ⚠️ **注意**：游戏（Unity/UE引擎）和 MT 管理器（画布自绘）无法被无障碍服务直接抓取输入框，属于系统级限制，勾选了也无效哦。
